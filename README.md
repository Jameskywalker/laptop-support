# 笔记本支架（拓扑优化 + 3D 打印）

适用于 13-14 寸笔记本的护颈支架，由 **左支撑 + 右支撑 + 中间横梁** 三个零件组成。
支撑的侧面轮廓经过二维拓扑优化，沿厚度方向拉伸成形；横梁是规则截面，不做优化。
网页预览：`web/stand_preview.html`（可以切换倾角方案）。

## 方案

| 方案 | 倾角 | 支撑轮廓 (mm) | 屏幕上沿离桌 (mm) | 屏幕竖直需转轴开到 | 打印量 (g) | 前部 150 N 误用应力：最大 / 前挡区 (MPa) | 倾覆推力：后 / 前 (N) |
|---|---|---|---|---|---|---|---|
| desk35 | 35° | 278.1 × 125.9 | ≈ 345 | ≥ 125° | 161 | 8.3 / 8.3 | 7.6 / 6.3 |
| desk40（选定） | 40° | 267.8 × 140.3 | ≈ 359 | ≥ 130° | 172 | 6.0 / 6.0 | 7.2 / 5.7 |
| desk45 | 45° | 256.2 × 153.7 | ≈ 373 | ≥ 135° | 181 | 4.2 / 4.2 | 6.8 / 5.2 |
| raised25 | 25° | 255 × 186.3 | ≈ 405 | ≥ 115° | 205 | 4.5 / — | 4.9 / 6.2 |

- **desk40（选定）**：前挡直接落在桌面，40° 倾角抬高屏幕；后脚伸出顶面后端 95 mm 防后翻。
- **desk35 / desk45**：同一思路的对比方案（同样加长了后脚）。
- **raised25**（上一版）：笔记本前沿离桌约 100 mm，25° 倾角整体抬高。

屏幕要竖直，笔记本转轴必须能开到 90° + 倾角。开不到的话，屏幕会向前倾，差几度就倾几度。

## 为什么用"二维优化 + 拉伸"

支撑打印时侧面贴着打印平台，所以侧面轮廓就是每一层的截面，沿 z 方向拉伸后**所有侧壁都是竖直的，天然没有悬空**。
横梁用卡扣连接，不用螺钉：支撑上开贯通方槽（也是轮廓的一部分），横梁两端的卡扣臂和卡钩都是平面图形沿厚度拉伸，同样没有悬空。
载荷全部在轮廓平面内，正好落在打印层面内这个强度最高的方向上。

## 前挡落桌方案的建模要点

- **前挡受力大**：笔记本重量沿斜面的分量 W·sinθ（40° 时约 64%）全部压在前挡上。
- **按压载荷的拆分**：竖直按压时，垂直斜面的分量压在顶面，沿斜面的分量全部算在前挡上，不计摩擦，偏保守。
- **前挡冲击工况**：增加了 40 N 的"前挡冲击"，模拟把笔记本滑进支架时撞到前挡。
- **前挡支撑交给优化**：前挡本身只保留很小的非设计区（8 × 15 mm，根部 R2 圆角），它下方和前方到桌面之间的区域都可以优化。结果是三个角度的优化都在前挡下方长出了一整块实体直通桌面。
- **约束**：前挡下的桌面只提供竖向支撑，后脚铰支。前挡受到的往前的推力必须通过结构自身（底杆）传到后脚，不依赖桌面摩擦。
- **横梁接口位置**：放在"顶面后端 → 后脚"连线上、离地约 45% 的位置，正好落在后腿上（`params.py` 自动计算）。

## 拓扑优化设置（`topopt2d.py`）

- **算法**：二维平面应力，Q4 单元，1 mm 网格。SIMP 罚因子 p=3，密度过滤半径 4 mm，OC 更新。
- **鲁棒公式**：腐蚀 / 中间 / 膨胀三场 Heaviside 投影，η = 0.7 / 0.5 / 0.3，β 从 1 逐步加到 32。这样可以保证杆和孔的最小尺寸。
- **体积分数**：前挡落桌方案 30%，上一版 25%。
- **非设计区**：顶面 5 mm 实体带、前挡、底边 5 mm、前后脚、横梁接口区（26×50 mm）。
- **工况**（多工况加权柔度）：自重、前部按压 30 N、转轴处按压 30 N、向后推屏 10 N、向前推机身 10 N、前挡冲击 40 N、横梁传力 (8, −15) N。
- **复核**：在最终几何上用 0.5 mm 网格重新计算，另加前部和后部各 150 N 的"手肘撑压"误用工况，并单独统计前挡区（前挡及其根部 25 mm 范围）的应力。

## 输出文件（`out/<方案>/`）

| 文件 | 说明 |
|---|---|
| `model/support_left.stl/.step`、`model/support_right.stl/.step` | 支撑。两片是同一个零件（纯拉伸体，正反对称），打印两份 support_left.stl 即可 |
| `model/beam.stl/.step` | 横梁，打印姿态：40 mm 宽面贴床；两端各一对卡扣 |
| `model/beam_outline.json` | 横梁平面轮廓（含卡扣） |
| `model/assembly.step/.stl` | 装配体（X 为左右方向，Y 为前→后，Z 向上） |
| `model/profile.json` | 优化后的二维轮廓多边形 |
| `model/verify.json`、`check.json`、`build_report.json` | 复核数据：有限元、前挡区应力、水密性、干涉、重量、倾覆 |

## 打印与装配

1. **材料**：PETG 或 PLA。层高 0.2 mm，3-4 圈墙，15-20% gyroid 填充，**不需要加支撑**。
2. **支撑**：两片是同一个零件，打印两份，任一侧面贴床。在 H3C 上两片可以放同一盘。
3. **横梁**：40 mm 宽面贴床。
4. **装配（卡扣，无螺钉）**：横梁两端的卡扣对准支撑上的方槽，用力推入，听到"咔"一声就扣住了。梁身台肩顶住支撑内侧面，卡钩扣住外侧面。拆卸时从外侧把两个卡钩往里捏再拔出。横梁建议用 PETG，反复拆装更耐用。
   - 卡扣参数：臂厚 2.5 mm，弹性段约 30 mm，扣入时向内弯 1.2 mm，最大应变约 0.5%。卡钩搭接 1.2 mm，伸出支撑外侧面约 4.2 mm。都在 `params.py` 里，可以调整。
   - 方槽单边间隙 0.2 mm。卡得太紧时把 `CLEAR` 加大；太松时把 `HOOK_H` 加大。
5. **配件建议**：在支撑顶面贴硅胶防滑条，在前后脚底贴橡胶垫。

打印机为拓竹 **H3C**（打印尺寸 330 × 320 × 325 mm，见 `params.py` 中的 `BED_W`、`BED_D`）。
前挡落桌方案的两片支撑可以排在同一盘（上下排列，最多占 316 mm），横梁另打一盘。

## 重新生成

环境（Python 3.12）：

```bash
uv venv .venv --python 3.12
uv pip install --python .venv/bin/python -r requirements.txt
```

```bash
./run_all.sh                 # 默认重算 desk35 desk40 desk45，并生成网页
./run_all.sh desk42          # 任意角度：deskNN；上一版：raised25
.venv/bin/python make_web.py desk35 desk40 desk45 raised25   # 只重新生成网页
```
